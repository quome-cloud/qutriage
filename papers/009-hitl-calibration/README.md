# Paper 009 — Calibrating Human Oversight for Clinical AI Agents

The stage-5 manuscript for the QUOKKAGUARD `oversight` layer: a calibrated
risk-escalation meta-layer that routes only the ambiguous tail of agent actions to
clinicians.

## Build

```
make paper        # tectonic preferred; falls back to pdflatex+bibtex -> main.pdf
```

## Regenerate every number and figure (deterministic, seed 42)

```
python3 ../../scripts/009-hitl-calibration/gen_triage.py        # TriageBench
python3 ../../scripts/009-hitl-calibration/fit_calibration.py   # fit calibration
python3 ../../scripts/009-hitl-calibration/run_experiments.py   # E1-E6 + kappa -> results/009-*
python3 ../../scripts/009-hitl-calibration/make_figures.py      # figs/*.png
```

Headline numbers live in `numbers.tex` (traceable to `results/009-hitl-calibration/*.json`);
the figures in `figs/` are generated by `make_figures.py`. The Rust layer is `src/oversight/`.
